# MyG-setup | Remastered

En moderniserad version av mitt tidigare projekt MyG-setup,
där jag presenterar min gamingdator, kringutrustning och gaminghörna.

Projektet är byggt från grunden med HTML och CSS, med fokus på
design, responsivitet och enkelhet.

## Innehåll

- Datorkomponenter och specifikationer
- Kringutrustning
- Showcase med egna fotografier
- Presentation av projektet
- Systemadministratören Kalle

## Teknik

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Starta projektet

Öppna index.html i valfri webbläsare.
Alternativt kan Live Server i Visual Studio Code användas.

Inga installationer eller externa beroenden krävs.
